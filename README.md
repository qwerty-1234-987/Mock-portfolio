# Personal Portfolio Website

A multi-page personal portfolio website developed using HTML, CSS, and JavaScript to demonstrate foundational web development skills.

## 🌐 Live Website
https://qwerty-1234-987.github.io/Mock-portfolio/

## Project Overview

The website includes separate résumé, cover letter, and career goals pages. It uses a shared external stylesheet, JavaScript functionality, locally stored multimedia, semantic HTML, and an interactive contact form.
